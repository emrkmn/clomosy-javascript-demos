# Clomosy JavaScript Integrations & Web Utilities

[![Platform](https://img.shields.io/badge/Platform-Clomosy-orange.svg)](https://clomosy.com)
[![Language](https://img.shields.io/badge/Language-JavaScript%20ES6+-yellow.svg)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Bu depo, **Clomosy** platformunda **JavaScript** kullanılarak geliştirilmiş deklaratif arayüz tasarımlarını, donanım köprülerini (Kamera, Barkod, GPS), RBAC navigasyon mimarilerini ve uçtan uca kurumsal mobil çözümleri içerir.

| [📍 Çok Birimli Saha & Yönetim CRM](./04-full-apps/field-operations-crm/) | RBAC Kurumsal CRM | 4 Bağımsız Modül, Barkod/QR Giriş, Donanım Kamerası ile Tutanak | ✅ Hazır |
| `01-webview-bridges` | WebView ve Köprüler | Yerel uygulama ile web arayüzü haberleşmesi | ⏳ Planlandı |

İlgili modüldeki `.js` dosyasını Clomosy Web IDE veya geliştirme ortamındaki script alanına yapıştırarak hemen test edebilirsiniz.
